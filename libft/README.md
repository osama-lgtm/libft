# DESCRIPTION
The main purpose of this project is to make later projects more clean and understandable, so that instead of rewriting the functions, we can just include the library and use the functions directly, this library is used for allocating memory , modifying and check out the variable's contents.

# INSTRUCTIONS
1-compilation
To compile the project, run this command in the root directory:
make
This will generate the static library file: libft.a 

2-installation

3-excecution
To excecute the functions used in the main function file and compile it with the library
cc main.c libft.a -I then-> ./a.out
